# Patterns & Techniques — $100M Offers

Use this as a routing map for the skill.

| Pattern | Job |
|---|---|
| Grand Slam Offer | Build a differentiated, value-driven offer |
| Category of One | Escape direct price comparison |
| Commodity Test | Diagnose price-driven comparison |
| Starving Crowd | Validate market demand |
| Four Market Indicators | Check pain, purchasing power, targetability, and growth |
| Price-to-Value Discrepancy | Support premium pricing |
| Value Equation | Increase perceived value |
| Fast Wins | Reduce perceived time delay |
| Divergent Thinking | Generate many possible solutions |
| Dream Outcome | Sell the destination rather than the mechanism |
| Problems → Solutions | Turn objections and friction into deliverables |
| Delivery Vehicles | Generate alternative ways to solve each problem |
| 10x / 1/10th Test | Stretch delivery assumptions |
| Sales-to-Fulfillment Continuum | Balance selling power and fulfillment burden |
| Trim & Stack | Keep high-value, workable deliverables |
| Scarcity | Add real quantity constraints |
| Urgency | Add real time constraints |
| Bonus Construction | Build bonuses around specific buyer obstacles |
| Guarantee Types | Choose appropriate risk reversal |
| M-A-G-I-C | Generate offer names |
| Offer Fatigue Refresh | Refresh wrapper/creative before rebuilding the core offer |

## Routing cues

### "What should I charge?"
Check market purchasing power, commoditization, buyer value, fulfillment economics, and the Value Equation before recommending a number.

### "Make this offer irresistible"
Work through market → Value Equation → problems → solutions → delivery → Trim & Stack before adding scarcity, urgency, bonuses, guarantees, or naming.

### "My offer is not converting"
Diagnose whether the constraint is market, commoditization, weak perceived value, unresolved obstacles, delivery economics, risk, or presentation.

### "Add bonuses"
Every bonus should map to a specific buyer obstacle or next problem. Avoid filler.

### "Write a guarantee"
Identify the buyer's feared loss, customer-controlled actions, business-controlled outcomes, cost at risk, measurement method, and remedy.

### "Name this offer"
Use M-A-G-I-C components, generate multiple options, shortlist by clarity and relevance, then recommend testing.

### "How can I productize this service?"
Map problems, generate several delivery vehicles, then Trim & Stack toward high-value, lower-marginal-cost solutions.
