# $100M Offers — Claude Code Skill

A reusable Claude Code skill for building, auditing, pricing, strengthening, packaging, and naming offers using operational frameworks from Alex Hormozi's *$100M Offers*.

The skill is designed to run the methods on real business work rather than summarize the book.

## Install

Add this repository as a marketplace:

```text
/plugin marketplace add keranjeth/akdaily-skills
```

Then install the plugin:

```text
/plugin install 100m-offers@akdaily-skills
```

## Test

```text
Use the $100M Offers framework to audit this offer. Diagnose it before rewriting it:
[paste offer]
```

## Main jobs

- Build an offer from a rough idea
- Audit an existing offer before rewriting it
- Diagnose commoditization and weak differentiation
- Apply the Value Equation
- Turn buyer obstacles into solutions
- Productize delivery using Trim & Stack
- Improve pricing logic
- Design legitimate scarcity and urgency
- Create objection-solving bonuses
- Choose an appropriate guarantee
- Generate offer names using M-A-G-I-C
